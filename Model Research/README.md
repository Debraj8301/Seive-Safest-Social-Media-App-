# Model Research Export

        This folder contains the model development and research assets for GitHub.

        ## Included
        - `index.ipynb`, `test.ipynb`: notebooks
        - `data/`: train/dev/test annotations and local inference artifacts
        - `test/`: example images used for testing
        - `clip_embeddings/`: saved embedding arrays
        - `lightgbm_experiment.py`, `prepare_local_inference_artifacts.py`: research scripts
        - `improvements.txt`: modeling roadmap and notes

        If you want a lighter GitHub upload, you can later remove large binary artifacts such as `.npy`, `.pt`, `.pth`, and `.joblib` files and rely on release assets or cloud storage instead.
